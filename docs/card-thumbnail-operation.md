# カード画像運用方針

おかずDBの作品カード画像は、品質を優先して「自動95%・手動5%」で運用します。

カード画像の目的は「パッケージを正確に表示すること」ではなく、一覧で作品を一番魅力的に見せる「代表画像」を選ぶことです。

## 基本方針

- 作品カードでは代表画像として `card_thumbnail_url` を最優先で表示する
- `card_thumbnail_url` がない作品だけ `thumbnail_url` にフォールバックする
- 作品詳細ページのメイン画像は従来通り `thumbnail_url` を使う
- サンプル画像、動画、アフィリエイトURL、SEO情報はカード画像運用とは切り離す

## 自動処理

通常の縦長表紙画像、またはサンプル画像の中に代表画像として自然に使える画像がある場合は、自動で `card_thumbnail_url` を設定します。

自動選択の優先順位は以下です。

1. 縦長パッケージ画像がある場合はそのまま使う
2. サンプル画像の中に、文字入り・ポスター風・タイトル風など代表画像として成立する画像がある場合は採用する
3. 適切なサンプル画像がない場合は、DVD全面画像の右側表紙を使う
4. それでも不自然なものは `NOW PRINTING` にし、`needs_review` に送る

普通のプレイシーンや通常の静止画は、サンプル画像であってもカード代表画像として採用しません。

## needs_review に送る条件

以下は無理に自動確定せず、`needs_review` として管理画面で確認します。

- コラージュ画像
- DVD全面画像で表紙部分をきれいに判定できない画像
- 白帯、裏面、説明欄がカード内に残る画像
- 低解像度でカード表示に向かない画像
- 自動切り出し後に表紙として不自然な画像

## 手動修正

管理画面の作品一覧から「代表画像を選ぶ」を使い、現在の `card_thumbnail_url` を確認しながら、パッケージ画像・DVD右側表紙・サンプル画像候補から1クリックで `card_thumbnail_url` を差し替えます。

適切な代表画像がない場合は `NOW PRINTING` に戻します。

この操作では、作品タイトル、出演者、メーカー、公式URL、アフィリエイトURL、公開状態などは変更しません。

## 10000件規模での運用

全件を自動で完璧に揃えるのではなく、95%を自動処理し、残り5%だけ人間が短時間で差し替えることで、品質と運用コストのバランスを取ります。
