# MyFans Affiliate Support Inquiry Draft

件名: Affiliate Centerの商品情報の連携・掲載可否について

MyFansサポートご担当者様

審査済みアフィリエイトメディアとして、購入可能なクリエイター・作品を検索できる紹介サイトを検討しています。実装前に、以下をご確認いただけますでしょうか。

1. Affiliate Centerの対象creator/postを取得できる公式API、feed、またはcatalog CSVはありますか。
2. creator ID/名称、profile URL、post ID/名称/URL、価格、thumbnail/OGP、報酬率、対象可否、自分用affiliate URLを定期取得し、当社DBへ保存して、承認済みメディアに表示できますか。fieldごとの可否をご教示ください。
3. 公式interfaceがある場合、認証方式、pagination、rate limit、推奨更新頻度、利用規約、削除・対象外変更の反映方法をご教示ください。
4. 公式interfaceがない場合、Affiliate Center画面の対象情報を自動取得・同期することは許可されますか。許可される方式と上限をご指定ください。
5. 「承認済みアフィリエイターのみに公開」のcreator/product情報を、当該affiliateの承認済み公開メディアに掲載できますか。不可の場合は完全に除外します。
6. 更新される検索結果・一覧などdynamic pageは、規約第6条の広告内容事前確認を、どの単位・方法・頻度で申請すればよいですか。
7. Affiliate URLのlink cardに表示されるOGP、creator profile画像、post thumbnailは、保存・加工・rehostせずに表示する場合と、当社で保存して表示する場合で、それぞれ許可条件は何ですか。
8. creator別売上CSV以外に、affiliate対象creator/postのcatalog exportはありますか。

併せて、現行公式資料間で以下の記載が異なるため、現在値をご教示ください。

- click attribution: 24時間 / 7日（168時間）
- 振込手数料: 220円控除 / MyFans負担
- 売上report: 個別作品detail表示 / aggregateのみ

回答をいただくまで、自動取得、DB投入、画像保存、認証APIへの直接accessは行いません。

よろしくお願いいたします。
